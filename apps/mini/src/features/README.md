## 📋 标准模块文档模板

每个模块的 README 应包含：

### 1. 模块概述
- 一句话描述
- 核心功能
- 优先级和状态

### 2. 文件结构
- 列出所有文件
- 标注核心文件

### 3. 核心功能
- 主要 API
- 类型定义
- 使用示例

### 4. 使用示例
- 在页面中使用
- 常见场景代码

### 5. 数据流
- 加载流程
- 更新流程

### 6. 数据格式
- 主要接口定义
- 示例数据

### 7. 测试
- 测试命令
- 测试覆盖情况

### 8. 依赖关系
- 依赖的模块
- 被依赖的模块

### 9. 注意事项
- 性能考虑
- 数据一致性
- 错误处理

### 10. 未来计划
- 计划功能
- 优化方向

## 🎯 快速创建新模块文档

### 步骤

1. 复制 `health-loop/README.md` 作为模板
2. 修改模块名称和路径
3. 根据实际情况填写各部分内容
4. 更新本索引文档

### 示例命令

```bash
# 创建新模块文档
cd apps/mini/src/features/health-records
cp ../health-loop/README.md ./README.md

# 编辑文档
# 修改标题、路径、功能描述等
```
