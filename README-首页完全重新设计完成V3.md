## 详细技术实现

### 主视觉区（参考建档页）

```vue
<view class="hero-fullscreen">
  <!-- 插画：widthFix 完整显示 -->
  <image
    src="/static/illustrations/home-hero-morning.png"
    mode="widthFix"
  />
  
  <!-- 渐变遮罩：60% 高度 -->
  <view class="hero-gradient" />
  
  <!-- 底部浮动信息 -->
  <view class="hero-body">
    <view class="today-summary">
      <view class="summary-row">
        <text>今日体重</text>
        <text>72.5 kg</text>
      </view>
      <view class="summary-row">
        <text>今日进度</text>
        <text>2/4 已记录</text>
      </view>
    </view>
  </view>
</view>
```

**样式关键点**：
```css
.hero-illustration {
  width: 100%;
  height: auto; /* widthFix 自动高度 */
}

.hero-gradient {
  position: absolute;
  bottom: 0;
  height: 60%;
  background: linear-gradient(
    to top,
    rgba(232, 247, 237, 0.96) 0%,
    rgba(232, 247, 237, 0.88) 35%,
    rgba(232, 247, 237, 0) 100%
  );
}

.today-summary {
  background: rgba(255, 255, 255, 0.92);
  backdrop-filter: blur(24rpx);
}
```

### 今日行动（2x2 网格）

```vue
<view class="actions-section">
  <view class="section-title">今日行动</view>
  <view class="actions-grid">
    <button class="action-btn action-btn--done">
      <view class="action-icon-wrap">
        <image src="weight-icon.svg" />
      </view>
      <text>体重</text>
      <view class="action-badge">已记录</view>
    </button>
    <!-- 其他 3 个按钮 -->
  </view>
</view>
```

**样式关键点**：
```css
.actions-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16rpx;
}

.action-icon-wrap {
  width: 96rpx;
  height: 96rpx;
}

.action-badge {
  position: absolute;
  top: 16rpx;
  right: 16rpx;
  background: linear-gradient(135deg, #7fcc8f 0%, #67a37b 100%);
}
```
