## 建档页为什么设计得好？

### 核心设计原则

1. **图片完整显示，不裁切**
   ```vue
   <image mode="widthFix" />  <!-- 宽度适配，高度自动 -->
   ```

2. **渐变遮罩确保文字清晰**
   - 68% 高度渐变
   - 从透明到半透明薄荷绿

3. **内容浮动在底部，不遮挡插画**
   ```css
   .welcome-body {
     position: absolute;
     bottom: 0;
     /* 浮动不遮挡主体 */
   }
   ```

4. **层次清晰**
   - 背景插画（z-index: 0）
   - 渐变遮罩（z-index: 1）
   - 内容层（z-index: 2）

5. **整体设计，不是卡片堆叠**
   - 插画 + 遮罩 + 内容 = 一个整体
   - 不是"卡片1 + 卡片2"的堆叠

## 新首页设计（完全不同）

### 主视觉区（参考建档页）

**之前的问题**：
- ❌ `mode="aspectFill"` 裁切图片
- ❌ 固定高度 480rpx，图片不完整
- ❌ 毛玻璃卡片遮挡插画
- ❌ 像"卡片套卡片"，不协调

**现在的设计**：
```vue
<view class="hero-section">
  <!-- 插画：widthFix 完整显示 -->
  <image 
    src="/static/illustrations/home-hero-morning.png"
    mode="widthFix"  <!-- 关键！不裁切 -->
  />
  
  <!-- 渐变遮罩：68% 高度 -->
  <view class="hero-gradient" />
  
  <!-- 底部浮动信息 -->
  <view class="hero-floating">
    <view class="today-brief">
      <text>体重 72.5kg</text>
      <text>已记录 2/4 项</text>
    </view>
  </view>
</view>
```

**关键改进**：
- ✅ **widthFix 模式**：图片完整显示，不裁切
- ✅ **渐变遮罩**：从透明到 rgba(232, 247, 237, 0.96)
- ✅ **底部浮动**：毛玻璃卡片不遮挡插画主体
- ✅ **整体设计**：像建档页一样，是"一个设计"
- ✅ **主次分明**：插画是主角，信息是配角

### 移除的冗余设计

**移除2：晨间问候卡片**
- 之前：aspectFill 裁切 + 毛玻璃遮挡

## 设计原则总结

### 从建档页学到的

1. **图片优先**：widthFix 确保完整显示
2. **渐变遮罩是好朋友**：确保文字可读
3. **浮动布局 > 绝对定位堆叠**：不遮挡主体
4. **整体设计 > 卡片堆叠**：首页是"一天的开始"
5. **简化、简化、再简化**：每个元素都有明确作用
