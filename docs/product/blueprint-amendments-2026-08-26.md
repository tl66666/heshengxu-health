# 产品蓝图修订：食品与拍照识别

本修订与 `heshengxu-product-blueprint.md` 同等有效，更新日期为 2026-08-26。

食品目录、每 100 克营养计算、手动餐食记录和历史营养快照已经进入 2B-1，作为减脂与体重管理核心体验的一部分。原蓝图中“首批不做食品目录”的探索期表述不再适用于当前实现。

拍照识别属于后续 2C。识别服务只能返回候选食品、置信度和估算克数，不能直接写入餐食记录；用户必须在小程序中编辑并确认候选结果。营养值始终从本地食品目录读取，历史餐食保存快照。

真实 Provider、CloudBase 对象存储和混元视觉调用必须在服务端完成，密钥只允许来自运行环境变量。无明确许可的数据、爬取 SQL、第三方图片和代码不进入产品仓库。
