## 配色方案（治愈系薄荷绿）

### 整体配色

```css
/* 背景（照搬薄荷的浅灰，换成薄荷绿） */
background: #f5f8f6;

/* 卡片（白色渐变） */
background: linear-gradient(135deg, #ffffff 0%, #fafcfb 100%);
box-shadow: 0 8rpx 28rpx rgba(127, 204, 143, 0.12);

/* 主色调（薄荷绿） */
--primary: #7fcc8f;
--primary-light: #e8f7ed;

/* 文字 */
--text-dark: #2d6943;
--text-gray: #76907d;
```

| 卡片 | 白色 | 白色渐变 |
| 主色 | 绿色 | 薄荷绿 #7fcc8f |
| 进度条 | 绿色 | 薄荷绿 |

### 从薄荷健康学到的

1. **白卡片为主**：统一设计语言
2. **大数字展示**：醒目直观
