## 📝 版本命名规则

### 格式
```
主版本号.次版本号.修订号

例如：V1.1.0
```

### 说明
- **主版本号**：重大架构变更
- **次版本号**：新增功能
- **修订号**：Bug修复和小优化

### 示例
- V1.0.0 - 初始版本
- V1.1.0 - 新增编辑卡片功能
- V1.1.1 - 修复编辑卡片bug
- V2.0.0 - 架构升级
