## 已知边界

- 本地演示使用 `dev-*` 开发 token；真实微信登录仍未接入。
- 序序仅展示规则化、基于记录的解释；自由聊天、个性化 AI 授权和风险支持页留在阶段 2C。
- 阶段 2A 不包含热量、食物库、扫码、拍照识别、周回顾、趋势图、情绪/肠胃/代谢记录、设备接入或商业功能。
- Windows 环境中的根 `pnpm` 偶发在内部 `pnpm install` 卡住。验收使用各应用已安装的本地 CLI 完成，不影响测试、迁移或构建结果。
- `@heban/domain` 使用 `dist/` 作为 API 运行时入口；构建 API 前必须先执行领域包构建，CI 已按该顺序执行。
