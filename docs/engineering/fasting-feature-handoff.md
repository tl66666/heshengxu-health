# 轻断食功能交接

更新时间：2026-08-30

## 页面边界

- 首页的轻断食卡片只展示入口摘要，点击进入 `/pages/fasting/FastingDetailPage`。
- 计划页只负责习惯计划和健康计划，不复用轻断食卡片作为“今日节律”内容。

## 已实现

- 16:8、14:10、12:12 三种模式。
- 用餐开始/结束时间选择器。
- 今日开始断食、结束并记录、用餐打卡。
- 环形阶段进度：用餐时间显示用餐进度，其他时间显示断食进度。
- 近 7 天日期条、断食 tips 和设置弹层。
- 本地数据 key：`heban.local.fasting.v1`。

## 素材规则

- 首页使用 `/static/icons/watercolor/fasting-clock.png`，这是专门的轻断食时钟图标。
- 计划模板使用完整场景插画，统一 `aspectFit` 和 148rpx 受控容器，不将大场景图当成小图标裁切。
- 当前素材已覆盖页面，不需要重新生成序序人物，避免人物风格漂移。

## 后续接 API

如果未来要跨设备同步轻断食，只新增独立 `fasting-plans` 资源和按用户归属的打卡记录，不要把轻断食塞进现有 `PersonalPlan` 的 `PlanTaskAction`，避免和健康计划语义混淆。
