# 薄肌养成交接

2026-10-12 · 本地功能实现 · 分支 feat/lean-muscle-cultivation

## 用户体验与入口

男性首页默认隐藏经期并显示薄肌养成；女性默认保留经期，可在卡片设置主动开启薄肌。未说明性别默认不展示经期。偏好按当前账号隔离，只有用户明确切换过的选项覆盖性别默认值，恢复默认不删除记录。

薄肌入口 `/pages/lean-muscle/LeanMusclePage`：总览 / 训练 / 圣经。二级页面分别为 TrainingPage、SettingsPage、BiblePage。训练支持日期补记、每组次数与负重、新增/修改/删除日志；目标可以建立当前周安排，后续调整下一周，尚未生效的安排可继续修改。

## 数据与计算

- 个人数据：`userStorageKey('heban.lean-muscle.v1')`。计划、日志、日确认、复盘、恢复周、收藏和阅读位置均按账号保存。
- 评分规则 v1：力量 35、饮食 25、睡眠恢复 25、个人进步 15。展示确定分项与潜在上限；缺少记录保留未知，不重新分配权重。结束周且证据完整时展示单一总分。
- 饮食来自真实 MealEntry；新增 `loadMealEntriesWithSource` 暴露完整读取状态。远端失败保持未知，不将本机空记录当作零摄入。完整确认绑定食物 ID、日期、餐次、份量和营养指纹，修改后必须重新确认。
- 睡眠读取现有 wellness-journal。成人目标与代表动作由用户确认；年龄资格本地优先、远端回退，未知档案暂不开放成人目标与评分。
- 通用运动记录和首页健康进度读取训练日志的派生视图，不重复写入另一份训练。通用记录页修改这种活动时进入 TrainingPage；日志增删改后视图同步变化。
- 每周按上海时区、周一至周日汇总。个别损坏日志/计划被过滤，其余有效数据保留。
- 记录目前本机保存，不包含跨设备同步。序序解释通过复制当前章节问题后进入已有对话，由用户确认发送。

## 圣经与素材

八章原创正文源：`docs/product/lean-muscle-bible.md`；运行 `node scripts/build-lean-bible.mjs` 生成 bible.ts。正文包含核心原则、说明、误区、行动与来源。阅读和收藏不直接加分。

模型生成原图：`assets/mini-icons/watercolor/lean-muscle/`，保留原图与完整提示词。`scripts/build-lean-art.mjs` 使用 sharp 制作 160px 派生 PNG，三张共 24448 字节；可传入安装 sharp 的 node_modules 路径，使用项目外的工具库时不修改业务依赖。art.ts 内嵌轻量图片，无需新增 CDN 文件。原图仍可通过原有资源导出流程归档。
