## 质量门禁

- 领域计算必须有先失败后通过的 Vitest 测试。
- API 必须通过 `tsc -p apps/api/tsconfig.build.json --noEmit`。
- 小程序必须通过食品/导航测试和 `npm exec -- uni build -p mp-weixin`。
- 每个真实识别结果必须显示为候选，用户确认后才写入餐食记录。
- 历史 GitHub Actions 红叉只表示当时提交失败；以当前 `main` 最新运行状态为准。提交前必须重新运行与改动范围相符的验证命令。
