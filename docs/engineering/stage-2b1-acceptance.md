# 阶段 2B-1 验收记录

**日期：** 2026-08-25
**范围：** Demo 驱动的正式小程序体验重构

## 验收清单

- [x] 未建档时只显示欢迎/建档路径，底部五栏不可进入。
- [x] 首页主行动、计划和任务均来自 `/daily-home/today` 的真实响应。
- [x] 首页最多显示三件待办；没有待办时不显示虚构任务。
- [x] 空记录、缺记录和全部完成使用对应的已审图，并不显示虚构健康分或趋势。
- [x] 记录创建和版本化修改后，首页、计划和记录页均通过 store 刷新。
- [x] 序序没有自由文本输入、模型调用宣称或医学诊断。
- [x] 微信构建产物包含 `app.json`、首页、记录、序序、计划和我的页面。

## 验证命令

```powershell
pnpm --filter @heban/mini test
pnpm --filter @heban/mini typecheck
pnpm --filter @heban/mini build:mp-weixin:check
```

Windows 本机 `pnpm` 在链接工作区解析时会触发安装路径缺陷；隔离工作区验收改为直接调用已安装的 `vitest`、`vue-tsc` 与 `uni` 可执行文件，结果与上述三个脚本等价。

## 明确边界

- 未接入自由 AI 聊天、CloudBase AI、图像识别、食物库或热量计算。
- 未实现趋势线、周回顾或健康评分；它们属于阶段 2B-2，且只可使用真实记录。
- 未实现提醒投递、数据导出和删除；“我的”页面不得将这些入口表现为已可用能力。
