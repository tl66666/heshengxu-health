## 暂存素材

以下素材目前不放入小程序首屏，避免为了“用上图片”而造成页面堆叠：

- `insight-report-banner.png`：后续健康报告页的横幅。
- `leaf-corner-decoration.png`：网页端或专题页的角落装饰，不用于小程序功能卡片。
- `xuxu-sleep-reminder.png`：睡眠提醒场景，等睡眠记录流程上线后使用。
- `hero.jpg`：网页端项目展示，禁止回流到小程序建档或首页。

新增图片必须先放入 `assets/illustrations/`，再由同步脚本复制到 `apps/mini/src/static/illustrations/`；接入前先确认原图比例、主体位置和目标容器比例。

## 页面审查基线

| 页面 | 插画策略 | 不允许出现的问题 |
| --- | --- | --- |
| Bootstrap | 仅使用竖屏启动主视觉，文字层只加轻遮罩 | 高透明遮罩洗白主体、横图塞进全屏 |
| 建档 | 欢迎步骤只使用方形序序主视觉；表单步骤不再叠加大图 | 图片加载失败后留下空白框、按钮被弹性高度拉伸、双导航 |
| 首页 | 一张 3:2 今日主视觉，序序头像仅作为入口提示 | 横图在非 3:2 容器中出现边缘空白、重复大卡片 |
| 记录 | 只有空时间线使用一张 3:2 欢迎缩略图 | 记录表单内堆叠场景图、横图变成非同比例贴图 |
| 序序 | 聊天内容只在欢迎、风险提示和头像位置使用方形插画 | 消息区用大背景图、输入区或 TabBar 留出无意义空白 |
| 计划设置 | 两个方向各使用一张方形缩略图 | 选择行同时叠加大背景图、未选方向出现裁切空区 |
| 计划 | 当前计划使用一个主场景；方向列表使用小方形缩略图 | 多张大场景图竞争注意力、完成插画重复出现 |
| 我的 | 只保留序序圆形头像 | 用装饰大图代替信息层级 |
