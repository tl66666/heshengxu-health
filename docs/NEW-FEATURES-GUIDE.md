## 📱 如何测试新功能

### 方法1：直接跳转（最简单）

在微信开发者工具中：
1. 点击顶部的"编译"按钮
2. 在模拟器中打开任意页面
3. 在"编译模式"下拉框中，点击"添加编译模式"
4. 设置：
   - 模式名称：喝水记录
   - 启动页面：pages/water/WaterPage
5. 点击"确定"并编译

### 方法2：从首页进入

修改首页的水图标点击事件：
```typescript
// HomePage.vue 中
const showWaterDialog = () => {
  // 跳转到喝水页面
  uni.navigateTo({ url: '/pages/water/WaterPage' });
};
```

## ⚠️ 如果编译失败

### 检查清单

1. **清除缓存**
   - 微信开发者工具 → 工具 → 清缓存
   - 勾选所有选项
   - 点击确定

2. **确认项目路径**
   - 必须打开：`apps/mini` 目录
   - 不是 `apps/mini/dist/dev/mp-weixin`
   - 工具会自动编译到 dist 目录

3. **检查 pages.json**
   - 确认新页面已注册：
     ```json
     {
       "path": "pages/water/WaterPage",
       "style": { "navigationStyle": "custom" }
     }
     ```

4. **重新编译**
   - 点击"编译"按钮
   - 或按 Ctrl+B
