## 4. 首页与卡片规则

| 档案状态 | 首次使用的默认入口 |
| --- | --- |
| 男性 | 经期隐藏，原位置显示薄肌养成 |
| 女性 | 保留经期；薄肌养成可在首页卡片设置主动开启 |
| 暂不说明 / 旧档案缺少性别 | 经期默认隐藏；薄肌默认显示，均可自行调整 |

默认推荐与用户主动选择分开保存。男性默认替换经期；卡片设置允许本人主动选择适用模块。修改性别后立即重新计算默认推荐，保留明确的手动偏好；不删除经期或训练历史。恢复默认仅重置当前账号的卡片偏好。

经期与薄肌使用独立 period / lean-muscle ID、文案和路由，不能把旧经期按钮直接改标题。首页和卡片编辑页共用一个规则函数，显示数量按实际可显示卡片计算。

## 5. 薄肌养成详情页

### 开始与设置

首次进入只收集当前方向（增强力量 / 减脂兼顾力量 / 保持状态）、经验（入门 / 已有训练习惯）、场地器械、每周可用天数与单次时间。优先复用健康档案和体重，不重复要求输入。

提供可编辑的入门安排与自行记录两种入口。默认计划覆盖全身，兼顾推、拉、腿部与核心，不仅练胸腹。成年人以每周两天、间隔休息的安排作为可修改的起点；是否增加训练频次由用户选择，不能仅因选择男性就自动制定高强度方案。未成年人或不适合常规模板的用户仍可记录活动，但不套用成人减脂、热量或蛋白目标。

### 今日训练

展示动作、组数、目标次数、用户选择的负重/自重方式、简短动作要点与替代动作。保存实际完成的每组次数和重量，可跳过、提前结束、补记或编辑。

训练完成以“保存实际记录”触发，不能仅点击“开始”就计为完成。进度按本周发生过真实力量训练的不同日期统计；同一天保存两次不重复增加天数。计划外力量训练也纳入汇总。

### 饮食与恢复

从现有餐次营养快照读取蛋白质和热量，使用记录中实际份量；显示“已记录摄入”，不假定用户已记录全天饮食。没有数据展示“待记录”，有食物缺少营养数据时标记“不完整”，不能用 0 冒充完整摄入。

首版显示实际值和用户自行设置的目标；不新增统一男性蛋白目标、不改变原有体重目标或轻断食方案。自动营养目标另行设计与审查。

睡眠从既有 journal 读取，明确日期归属；没有睡眠记录则提示补记。休息日视为计划内行为，不使用连续训练天数激励用户天天练。

### 进步与每周回顾

展示真实训练天数、训练日志、同一动作的次数/负重变化及体重趋势。动作名称相同但方式不同（如跪姿和标准俯卧撑）不直接比较。不同器械的重量不合成一个“力量评分”。

体重不下降时仍可展示“同一动作完成次数提高”。腰围、体脂和照片可在后续版本作为自愿记录扩展；首版不估算体脂。增加下文定义的薄肌评分，评分衡量个人养成目标的执行，不等同于外形达成率。

### 序序联动

“帮我看看本周安排”由用户主动触发。发送必要的结构化训练摘要与已记录饮食、睡眠信息，并明确缺失数据。首版可以先跳转现有聊天入口；自动注入这些数据前应核对当前聊天契约与服务端边界。保存任何 AI 建议为计划前由用户确认，AI 不直接重写训练安排。

## 6. 数据与工程边界

- 首页 profile 读取复用已有 loadProfileForDisplay 思路：当前账号本地优先，缺失时读取远端。onShow 刷新；切换账号时清空旧状态并忽略过期异步响应。
- 卡片偏好保存为当前账号的 userStorageKey；旧全局值无法可靠判断所属账号，不批量复制到每个账号。未能确认归属时采用当前账号默认配置，保留旧值供后续迁移判断。
- 新增 lean-muscle 模块，拆分计划/日志存储、校验、训练汇总与展示适配，避免继续扩充 HomePage.vue 中的业务规则。
- 新训练日志至少包含 id、实际训练日期与时间、可选 planId、每个动作的稳定 ID 和变式、每组 reps 与 loadKg、实际时长、状态和备注。
- 训练日志是薄肌力量数据的唯一来源；通用运动记录通过 sourceSessionId 与它关联。新建、编辑、删除保持一致，汇总时去重，避免一次训练被统计两遍。
- 历史通用力量运动只有时长时，可以计为已记录训练日，但明确“未记录组数”，不补造重量。增加共享力量类型判定，统一现有 strength/squat/push-up/plank/dumbbell 等类型。
- 对本地日志写入与通用运动记录写入采用可重试的同源 ID；失败保留待同步标记，不能展示假保存成功。
- 新日志与计划首版本地优先、按账号隔离；本次不承诺跨设备同步。切换性别只改变推荐入口，不改变数据归属。
- 记录日期按 Asia/Shanghai 汇总周一至周日；补记、跨周与删除后重新派生统计。新增输入校验和存储损坏回退。
- 页面注册、首页路由、卡片编辑、当前账号清理入口一起更新；首页与详情 onShow 读取最新数据。

## 8. 第二版信息架构与完整闭环

进入薄肌养成后以“总览 / 训练 / 圣经”三个页签组织，评分详情与训练日志作为二级页。避免为每个指标增加一级页面。

总览顺序：本周评分与记录完整度 → 今日训练或恢复 → 饮食和睡眠 → 当前推荐圣经章节 → 个人趋势与周回顾。首页原经期卡片只显示最近完整周的评分、本周训练进度和入口；首次使用展示“开始薄肌养成”。

闭环为：了解一条原则 → 选择适用计划 → 保存真实训练/饮食/睡眠 → 查看评分解释 → 找到下一个行动 → 回到相关章节。圣经支持独立阅读，不强制先建计划；评分不会因读文章直接提高。

三个评分方案：照片或体脂驱动的身材评价需要额外验证与敏感数据；完全由 AI 打分难以稳定复算；推荐采用有版本号的固定养成规则，AI 只解释结果。产品以“薄肌评分”为名称，副文案固定为“本周养成表现 · 根据已记录数据计算”。

## 9. 薄肌评分 v1

### 9.1 评分构成

| 维度 | 分值 | 意义 |
| --- | --- | --- |
| 力量训练 | 35 | 是否按个人周目标完成真实训练 |
| 饮食支持 | 25 | 已确认完整记录的蛋白目标与饮食结构 |
| 睡眠恢复 | 25 | 睡眠目标与计划内恢复 |
| 个人进步 | 15 | 代表动作的个人目标和每周复盘 |

这些权重为本产品的透明设计规则，尚未经研究验证为薄肌或健康预测模型。不同训练目标、规则版本的分数不做排行榜或横向比较。首版只比较同一用户、相同规则与目标快照的完整周；修改目标后的变化标注“目标已调整”。

### 9.2 可复算的计算规则

以下分值先使用浮点数计算，维度展示保留一位小数，总分在最终相加后四舍五入到整数，范围 0–100。

1. **力量训练 35 分**：`35 × min(有效力量训练日数 / 本周目标训练日数, 1)`。有效训练至少包含一个实际完成的正式组；同日重复记录只计一天，不以打开页面、开始计时或保存空日志计分。计划外训练按同样规则计算。旧力量记录仅有时长时提示补充一个动作正式组以参与该分项，仍保留在活动汇总中。
2. **饮食支持 25 分**：蛋白目标 15 分 + 饮食结构 10 分。每个有效饮食日的蛋白因子为 `min(已记录蛋白克数 / 用户确认的当天目标克数, 1)`；饮食结构因子为“当天包含蔬菜/水果、蛋白来源、主食的主要餐次比例”，使用现有餐次结构标记或用户确认，不能从热量反推。两项均按完整七天的日因子求和后除以 7。用户确认“全天已记完”且必要营养字段可用才视为有效日。未设置蛋白目标时该项待设置，不自动套用固定男性目标。没有主要餐次且确认未进食时，结构因子为 0，界面建议正常进食，不给断食额外奖励。
3. **睡眠恢复 25 分**：睡眠 20 分 + 恢复安排 5 分。每日睡眠因子为 `min(实际睡眠分钟数 / 个人睡眠目标分钟数, 1)`，七天平均后乘 20。用户确认采用年龄适用的目标；成人默认建议参考 CDC 的年龄分组，不把“越久越好”写进界面。恢复因子为“已确认按安排休息的恢复日数 / 本周计划恢复日数”，封顶后乘 5；按计划休息、主动因疲劳调整为恢复日可被确认，未确认则待补。计划缺少恢复日时先修订安排，该分项不因每天训练自动满分。
4. **个人进步 15 分**：代表动作目标 10 分 + 周复盘 5 分。周初选一至两个代表动作及其目标，例如“相同重量和变式下，指定一组完成 8 次”。每个目标因子为指定比较组实际完成次数与目标次数之比，封顶 1，平均乘 10；比较要求动作、变式、器械和负重一致，不用全部组的总次数代替指定组，不跨器械推算力量。用户可以选择保持现有能力，维持达成同样计分。更换动作或负重需要明确重新建立基线。周复盘写下或选择一条观察，并确认下一周一个行动后得 5 分；仅看文章、打开周报不计分。首次设置的目标为入门基线目标，不要求已经存在历史最佳纪录。

目标配置在周初或本周开始使用时生成快照。用户可以临时调整安排，但历史目标不可被悄悄替换以提高分数；生病、疼痛等情况下允许暂停评分、照常记录，界面显示“恢复周”。不催促为了补分增加训练。

### 9.3 不完整数据和周中状态

采用上海时区周一至周日。周中呈现“已确认得分”和“待完成/待记录”上限，不把未来日期计作失败。缺少数据时显示区间或“建立记录中”，不重新分配未知维度的权重凑成高分。

每个分项返回 confirmedPoints、possiblePoints、evidenceCoverage、status（ready / partial / needs-target / paused）以及缺失原因。区间下限取已确认的事实，上限仅把未知的分项按其剩余容量补足；本周已确认未完成的行动不能继续计入未知上限。已经记录的训练日、代表动作成绩与已完成复盘无需再次确认。

记录完整度按各分项权重加权的证据覆盖率计算，独立于得分。饮食的蛋白和结构、睡眠、恢复和每日训练状态分别有覆盖度；没有训练日志的日期由简短日确认区分“休息 / 未完成 / 尚未记录”。所有维度可评价、周结束且证据覆盖完整时才显示单一最终总分，其他情况下显示区间和记录完整度。没有数据时显示“建立记录中”，不显示 0 分。总分区间整数下限向下取整，上限向上取整。

明确的 0 是用户已确认未完成或真实测量值；未记录是未知。修改/删除日志后重新计算派生结果，旧周报注明更新时间。不同版本保存各自规则和目标，升级不重写旧历史分数。

### 9.4 评分解释与行动

完整周展示例：78 / 100；训练 28 / 35，饮食 20 / 25，恢复 21 / 25，进步 9 / 15。这里只是设计示例，不能注入正式记录。

点击任一维度显示：本周事实 → 公式和目标 → 待补记录 → 一个可执行建议。分数颜色使用同一绿色深浅；标签采用“刚开始 / 正在形成节律 / 节律较稳定”，只在最终分分别低于 50、50–79、80–100 时出现。未知数据不给等级；标签表达习惯状态，不给用户贴体型身份。

评分页面必须展示一句简短解释：“分数反映记录中的养成表现，身体变化通常需要更长时间观察。”配合动作趋势呈现实际结果。体重降低、吃得更少、超额蛋白、额外训练、长时间睡眠、购买补剂或阅读次数都不额外加分。

## 10. 薄肌圣经

页面标题采用用户要求的“薄肌圣经”，副标题“从理解到行动的力量养成指南”。内容为和生序原创整理，保留邵艾伦视频的出处与观点边界，采用 WHO / ACSM / CDC 原始资料支持具体健康原则。全文草稿见 docs/product/lean-muscle-bible.md。

八章结构：

| 章 | 内容 | 行动入口 |
| --- | --- | --- |
| 1 认识薄肌 | 肌肉基础、体态、可持续的生活习惯 | 选择自己的方向 |
| 2 从一次开始 | 居家/健身房、时间预算、入门与已有经验 | 生成可编辑训练安排 |
| 3 记录与进步 | 组数、次数、变式、负重、合适的个人目标 | 建立代表动作基线 |
| 4 吃得支持训练 | 餐次结构、食物份量、蛋白来源与记录误差 | 打开饮食记录 |
| 5 恢复也算训练 | 年龄适用的睡眠、恢复日与疲劳感受 | 查看恢复日 / 补记睡眠 |

每章固定结构为“一句核心原则 / 三条实用说明 / 常见误区 / 今天一个行动 / 资料来源”。阅读时间按实际字数估算，不预置虚假阅读人数。支持收藏、最近读到的位置和字体大小。阅读进度与行动完成分开记录，完成行动由关联真实记录判定，不能靠打开页面解锁训练完成。

提供“入门七天”行动导航：选择方向、第一次训练、记录一天饮食、安排恢复、第二次训练、观察动作变化、周复盘。实际训练日期按用户安排调整，不强制连续七天训练。提示可跳过、不失去之前进度。

用户点击“解释给我听”再调用序序；以当前章节及来源摘要作为上下文，模型只提供解释或建议。规则分数由客户端/领域函数计算，不能由聊天模型改写。首版 AI 非必需，模型不可用时正文和行动仍可使用。

原视频用清晰外链提供；小程序优先复制链接并提示浏览器观看，App 可使用已有外链打开方式。不得假定 B 站能在未配置合法业务域名的 web-view 直接播放。使用原创章节，不复制长篇字幕，不生成邵艾伦的声音、头像或授权标识。

## 12. 新增工程工作与验收

- 增加评分规则模块，输入统一的数据快照与目标版本，输出分项、区间、证据覆盖和解释 ID；不依赖网络或聊天模型。
- 增加每日证据确认状态、周目标快照、代表动作比较目标、暂停状态与周复盘。任何已经确认完整的饮食日被新增/编辑/删除食物后，重新标记需确认；确认时保留营养字段完整性检查。
- 代表动作稳定 ID 包含变式、器械和重量单位；负重、自重与辅助重量分别建模，零负重不代表缺失数据。
- 圣经采用带稳定 chapterId、contentVersion、来源链接和 actionId 的静态内容；收藏和阅读位置按当前账号保存，公共正文无需重复存储。
- 评分和内容都可离线查看；个人 AI 联动只在主动触发时发送必要数据。旧记录无需强制补齐即可继续使用其他健康功能。
- 验收新增：各公式的上限与舍入、缺失与真实 0、重复训练、跨周、目标修改、恢复周、营养完整度失效、动作不可比较、不同规则版本、阅读不刷分、图片透明与小尺寸可读性。
