# 小程序交互与序序聊天改造设计

**状态：** 已确认并进入实施

## 目标

把 Demo 中清晰可见的返回、底部导航、序序聊天和场景入口迁移到正式微信小程序，避免用户看到页面却不知道如何退出、跳转或提问。

## 交互边界

- 首页、记录、序序、计划、我的是五个底部 Tab，不重复显示返回按钮。
- 建档和计划设置是普通页面，顶部提供返回；建档首屏提供“退出建档”，退出前确认并回到启动页。
- 序序页面提供欢迎状态、授权数据摘要、快捷问题、规则化消息气泡、输入框、发送按钮和风险提示。当前不接真实模型、不声称诊疗。
- 页面内图标使用 `uni-icons`，禁止使用 emoji、Unicode 字符或手绘 SVG 代替导航图标。

## 组件边界

- `AppNavBar`：普通页面标题、返回和关闭动作。
- `MiniTabBar`：五个 Tab 和中央序序入口，只负责导航。
- `XuxuChatComposer`：快捷问题、消息列表和输入发送状态。
- `XuxuPage`：组合序序视觉、授权范围和安全说明。

## 验收

1. 建档和计划设置可以返回；建档首屏退出会确认。
2. 五个 Tab 均可点击并显示选中态。
3. 序序快捷问题会产生用户消息和规则化回复；输入框发送后清空并显示回复。
4. 任何页面不出现 `⌂`、`◷`、`▦`、`●`、`›` 等字符图标。
5. TypeScript、Vitest、微信构建和构建产物检查全部通过。
