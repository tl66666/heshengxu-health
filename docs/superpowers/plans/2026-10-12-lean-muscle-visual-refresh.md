# 薄肌视觉升级与双端打包

用户已授权自主设计、生成素材与双端打包。

## 方向

采用运动手账与实体旧书的组合。总览以奶油色为底，陶土橙、湖蓝、草绿和黄铜金建立各区块语义；训练场景插画增加主视觉。圣经目录用皮质旧书封面，正文用模型生成浅羊皮纸作为纹理，标题与中文正文仍为真实可编辑文字；书脊、页边、细线纹饰、章号和页码由 CSS 呈现。

- [ ] 更新首页入口、总览、评分、训练区、圣经目录与阅读页，保留已有业务行为。
