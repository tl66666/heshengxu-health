# 书柜深度内容与页面体验检查

用户授权自主规划、实现、检查；仍只更新开发预览，不打包、发布或修改已有认证工作。

## 产品设计

五个主题各八篇、合计四十篇指南，按主题从入门、操作到复盘排列。新增内容必须包含具体步骤、判断条件、常见误区、执行清单和来源；保留人物意见与产品实践的边界，健康内容不增加统一体脂、补剂或强制饮水目标。薄肌圣经的八章继续作为长文专题入口。

阅读页支持章节序号、预计阅读时间、手动标记读完、前后篇及目录；书柜显示各主题真实阅读进度。阅读状态不计入健康评分。行动升级为计划日期、可勾选执行清单、复盘笔记、进行中/已完成筛选。保存明确反馈，旧 v1 收藏和行动兼容，数据按账号隔离。

回看指南与行动时复用现有书柜页面，避免反复压入微信十层页面栈。搜索、收藏、未读条件有可见的清除与空状态恢复入口。

## 视觉与页面检查

先查 320/375px 的真实 Vue 页面，修正中文孤字换行、书封标题/注释、图文重叠、过窄按钮、二次描边、选中状态和长文来源阅读。检查首页、记录、计划、我的、薄肌总览/训练/设置/圣经、指南、饮水/体重/睡眠/运动/心情详情。丰富入口与内容结构，不用不存在的数据填满界面。

需要的书柜空状态素材调用模型生成；保持正文的阅读对比，图片用轻量衍生图与失败回退。动效短且可降级，不重复移动正文。
